## How the build differs from the design

- **D7's "information line":** wrong assumptions stay in P3 as `spec gap` rows, with the rule text saying the spec and server agree. There is no separate section. Same information, and no extra report shape.
- **D8 timeouts:** not added. A failed probe after the batch already gives `SUSPECT_ENV` → `ENV`. "Slow probe" isn't measured, so `TIMEOUT` stays `INSUFFICIENT_EVIDENCE` as before.
- **Properties cover reads and collection creates only.** A generated PUT/PATCH/DELETE to a random ID (Hypothesis picks small integers) could hit another test's data on the shared database.
- **`TP_RATE` (5 req/s)** applies to every black-box test, not just the families.
- **The curl in a `SPEC_MISMATCH` shows `Authorization: [Filtered]`** (Schemathesis masks it), not a `$TP_TOKEN` placeholder.
- **The ceiling for an external reach is left to E** (one comment in `ceiling()`).
