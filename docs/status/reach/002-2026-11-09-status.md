## How the build differs from the brief and the design

- **D8, no `.env` file at all.** Example values are passed as compose's process environment, like the generated ones, and only for the names the compose file references. The brief said to copy the example into the run's compose dir. Compose reads `COMPOSE_*` settings from a `.env` there, so a copied file would let the repo steer compose. Names starting `COMPOSE_` or `DOCKER_` are never passed.
- **A found bug, fixed:** the image-only refusal ran after the patch was applied, so an image-only target with a patch failed on the patch instead. It is refused first now.
- **Names (C11):** fixture slugs are `it3-p2-*`, so the projects are `tp_bb_it3_p2_*` and the images `tp-it3_p2_*`. The stand-in stub is `tp-it3-p2-standin:p2-dev`. The tests remove both.
- **`discovery.py`:** besides `step_reach`, one import line (`reach as reach_mod`).
- `python:3.14-slim` was pulled once (W0's base image, no longer on this Mac).
