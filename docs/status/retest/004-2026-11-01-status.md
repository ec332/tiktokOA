## 3. Gotchas found during M5

- **One stack at a time.** Single-worker rule; Docker tests (`pytest -m docker`, run by default locally) use the reference stack and will clash with a live run. CI runs `-m "not docker"`.
- **A `fixed:` image build patches the shared SUT tree for the duration of the build.** Don't run anything else against the tree meanwhile. If a build is killed, `build()` now refuses with the undo command.
- **Re-running a stage with options:** `tp stage run <stage> --input type=sha256:… --opt k=v`. With `--from-run`, `--opt` now replaces that run's `run_options` entirely. Run 24 (x252's) has no heads of its own: pass x252's inputs explicitly with `--input`.
- **zsh does not word-split `$VARS`**: put long `--input` lists in a bash script.
- **Status docs are git-ignored** (`docs/*`): add them with `git add -f`. Commits are owner-tagged (`[baseline] …`) and may touch only that owner's paths (`tp check-folders --commits`).
- The reference stack `tp_reference` is left up.
