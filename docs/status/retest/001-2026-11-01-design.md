# Retest stage — design (M5: V1–V3)

Agreed with the user on 2026-11-01 ("go with the recommended implementation"). Every recommendation below taken. Lean POC: V1–V3 only. `ReGate` (stretch) and V4 `IterationFeeder` (M7) parked. No LLM in this stage ($0).

| # | Topic | Plan said | Agreed | Why |
|---|---|---|---|---|
| D1 | Inputs | failing `run_records` + `triage` finding + variant | Consumes `run_records`, `triage`, `bound_tests`, `gate_report`, `run_options`. Options: `defect` (a triage defect id, e.g. `D-reference/O-6`) and `after` (the variant to retest on). Invoked as `tp stage run retest --from-run r-N --opt defect=… --opt after=…` | Tests come from the same artifact by id, so hashes match unless someone swaps them |
| D2 | Changed test (V1) | changed test → `RETEST_INVALID` | `bound_tests` defaults to the run's head; `--input bound_tests=…` overrides it. `SameTestCheck` compares, for each test of the defect, sha256(source) + `lock_hash` against the `bound_tests` named in the failing run's `manifest.json` | That is the real failure mode: a suite regenerated after the fix |
| D3 | Fix variant | `fixed` | Env variant kind `fixed:<patch>`: no flags, `sut/patches/<patch>.patch` applied on top of the `sut.yaml` patches **only while the image is built**, then reversed. The image tag and the fingerprint's `sut.patches` include it. Not added to `sut.yaml` (that would fix reference). Flag-off retest = `reference` | Smallest env change; `[env]` commit |
| D4 | `EnvDiffCheck` | only code hash or flags may differ | Allowed to differ: `flags`, `images.backend`, `services.backend`, `sut.patches` (only by added patches). Anything else → `INCONCLUSIVE` | The env fingerprint's real fields |
| D5 | Fingerprint source | — | Execute stores the full `fingerprint` per variant in `run_records` (execute 1.0.0 → 1.1.0, `[execute]`). A failing run without one → `INCONCLUSIVE` ("re-run execute") | Old runs only have `spec_hash`, which always differs between variants. The demo needs one fresh execute run |
| D6 | FailToPass | K=5; intermittent K from (1−p)^K | Every test of the defect 5/5 `PASS` on `after`. Intermittent K parked (`shortcut:` comment) | No intermittent defect exists; the race is `CONSISTENT_FAIL` |
| D7 | PassToPass | linked criteria + flow first, then full main lane | Full suite at K=5 in one batch per attempt. Tests `PASS` on the before variant must `PASS` after. Other tests that failed before are listed separately with their after state | Order doesn't matter inside one pytest batch |
| D8 | Executor | called as a library | `ExecuteStage().run(ctx, …)` with `run_options {variants: [after], k: 5}`. Execute also runs reference first; accepted (~100 s, gives a fresh "before" for a `fixed:` retest) | No execute refactor |
| D9 | Verdict | 5 verdicts; closes only on `FIXED_CONFIRMED` | Order: `RETEST_INVALID` > `INCONCLUSIVE` (env diff, or any defect test `SUSPECT_ENV`/`NOT_RUN`) > `NOT_FIXED` > `FIXED_WITH_REGRESSION` > `FIXED_CONFIRMED`. `closed` = verdict is `FIXED_CONFIRMED`, recorded in the artifact only | Report runs before retest; nothing reads a defect state |
| D10 | Label | "own patch on upstream" | Field `fix_kind`: `flag off (seeded)` or `own patch on upstream` | No new core label |
| D11 | Scope | — | One defect per call. M5 = `D-bug:BUG_OWNERSHIP_UPDATE/…` → `reference`, and `D-reference/O-6` → `fixed:fix-pagination` | Each defect has its own after variant |
| D12 | `tp run` | 9 stages | No `defect` option → `{"retests": [], "note": "no fix supplied"}` | Unattended run keeps working |
| D13 | UI | before/after table, evidence side by side | Plain table panel: defect, before/after distributions, hashes equal, env diff, verdict, run folders. Side-by-side evidence parked | Lean |
| D14 | Fix patch | `sut/patches/fix-pagination` | `skip: int = Query(0, ge=0)` **and** `limit: int = Query(100, ge=0)` | O-6 includes TC-O6-3.a / TC-O6-4 (`limit=-1` → 422). No upper bound on `limit`: O-7 was overridden to SPEC_GAP |
| D15 | CLI options with `--from-run` | — | `tp stage run … --from-run` currently takes `run_options` from the old run, so `--opt` is lost. Fix: `--opt` given → a fresh `run_options` override (`[skeleton]`) | Otherwise D1's invocation can't work |

Owners: `tp/stages/retest/`, `sut/patches/fix-pagination.patch`, `web/src/panels/retest/` (`[retest]`); D3 in `tp/stages/env/` (`[env]`); D5 in `tp/stages/execute/` (`[execute]`); D15, `docs/folders.yaml` M5, stub deletion (`[skeleton]`).
