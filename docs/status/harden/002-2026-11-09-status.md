## How the build differs from the brief and 001

1. **`//…` targets aren't refused, and needn't be.** Python's `BaseHTTPRequestHandler` folds a leading `//` into `/`, so they reach the configured upstream only (asserted in the H3 test).
2. **The lock skips stub runs.** They touch no target, and the API tests start several at once.
3. **The M2 proof is a scripted fake env, not a contract-changing patch on the template** (no Docker in wave 1). I1 can run it on the template.
4. **`targets/fastapi-template/profile.yaml` didn't change.** `data.factories` and `reach.app_service` were already there; the code now reads them.
5. **`platform_rt/tests/test_rt_plugin.py` gained one line** (`TP_API_BASE=/api/v1`). It pinned the removed `/api/v1` default. It isn't in the brief's Owns; it goes with the `api.py` grant (001 H5).
6. **M2's operation under test** comes from the failing attempts' recorded exchanges (`triage.rules.under_test`). No recorded request, or a spec that can't be fetched, gives INCONCLUSIVE.
7. **The README isn't committed yet.** Its diff is shown to the user first (001 H7).
