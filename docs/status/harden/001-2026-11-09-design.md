| # | Decision | The brief said | Agreed | Why |
|---|---|---|---|---|
| H1 | Where the per-target lock lives (L3) | The run table, because a crash leaves no stale lock | The run table. `runner.busy(slug)` uses discover/006's rule: a run holds a target while it is `running`, or `awaiting_review` after its env stage succeeded. Checked in `start_run` and in `advance` | **The reason is corrected:** a crashed run stays `running`, so the table can hold a stale lock too. That lock is visible in `GET /runs`, and `tp cancel` clears it; a lock file is hidden. Checking in `advance` covers resume and retry |
| H2 | `Host` on the loopback rewrite (L4) | Keep the original `Host` | The proxy sends `$TP_UPSTREAM_HOST` as `Host` when it is set. `egress()` setting it is a Request (P2's file) | The `Host` the runner sends is the proxy's own name, so "the original" is the target's base-URL host, and only `egress()` knows it |
| H3 | When an item counts as owned (M1) | A 201, or a Location header with the run prefix | A 201, or a 2xx whose response body carries the run prefix | Get-or-create answers 200 with someone else's data. Location headers rarely carry names |
| H4 | What counts as a contract change (M2, DR-10) | Diff the served OpenAPI | Strict equality of the operation under test, with `$ref`s resolved, between the before and after variants' served specs. A change, or a spec that can't be fetched, gives INCONCLUSIVE plus a `contract_diff` field | DR-10 says "unchanged". A new verdict value would ripple into P3's report and UI. Black-box `Reach.openapi` ignores the variant (L5, P2), so M2 is proven on the template only until P2 lands |
| H5 | Widened allow-list (L1) | Widen to `platform_rt/`, `config/` and prompts | Widened to `platform_rt/` and `config/`. Prompts are already under `tp/`. P1 is granted `platform_rt/platform_rt/api.py` for its 2 literal lines. Retest reads the app service from the profile, not `images.backend` | "Zero" is in the Done-when, and nobody owns `api.py` |
| H6 | Proxy request rules (H3, M3, M4) | As in scope 1 | Origin-form only (`/…`, not `//…`), checked before anything else. Strip `X-HTTP-Method-Override`, `X-HTTP-Method` and `X-Method-Override`. Refuse `_method` in the query, in a form body, or as a top-level JSON key. Deny words apply to every read, since the proxy only serves external reach | Frameworks differ on where they read `_method`; refusing it everywhere costs nothing |
| H7 | README | Correct review §4's claims | Only the overstated and unverified rows. The diff is shown to the user before it is committed | — |
