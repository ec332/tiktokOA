## Regressions this work introduced, found by the live runs and fixed

- **Per-test timeout shorter than the read-back.** Raising `read_back_timeout_s` to 120 (in `005`) collided with `platform_rt`'s 60 s per-test timeout: r-0012 had TC-C8-1 and two others ERROR with `TIMEOUT`. The black-box runner now sets `TP_TIMEOUT = max(60, read_back + 60)`; the gate can still override it.
- **The "lone principal is the caller" rule (in `005`, fix 2) broke anonymous cases.** It added `admin` to cases whose anonymity is stated in hints or steps, so the scaffold required a token and 3 cases went UNBOUND in r-0012. The rule is removed. Unknown preconditions still become `Given:` steps. Who the caller is goes back to the binding, and the black-box `make` text now says "send every request as the admin unless the case says the caller is anonymous". The scaffold still counts an explicit `admin` precondition as a caller.
