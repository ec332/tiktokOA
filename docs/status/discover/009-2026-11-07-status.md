
## 6. Lessons from this session

- **Check the stage document's Rules and Steps tables, not only "Done when".** `004` and `005` marked D done too early; an independent review (`006`) found the web flow couldn't use a discovered target.
- **`tests/test_target_literals.py` scans tracked files only.** A new file passes locally until it's committed. Run it after `git add`.
- **New probes renumber the recorded probe logs and break byte-identical replays.** Put extra facts at the log's top level (as `commit` is) instead.
- **Tests that write under `data/` need `TP_DATA` isolation:** `tp/stages/discover/tests/conftest.py` has it. Module-scoped fixtures run before the per-test one.
