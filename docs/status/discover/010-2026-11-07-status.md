| Job / step | Result |

## Decision

The user chose not to rewrite published history: **no force-push.** The red run stays in history with this note. CI checks only each push's new commits, so the push carrying this file is checked on its own.

## Lesson

Before pushing, run the folder rule over the push range, not only `tp check-folders`:

```bash
uv run tp check-folders --commits origin/main..HEAD
```
