## Rules that bit this session (do these)

- **Gate every commit on the suite's output, not on a pipe's exit code.** Write `uv run pytest -q -m "not docker" > <scratch>/suite.txt 2>&1`, then commit only when the last line has no `failed` **and** no `INTERNALERROR`. A pipe through `tail` hid a red allow-list test, and a full disk truncated a run to 116 tests.
- **Never name a target in platform code, comments included.** `tests/test_target_literals.py` scans `tp/`, `platform_rt/` and `config/`, so a comment saying "Memos" fails it.
- **Bump platform_rt** (both `platform_rt/pyproject.toml` and `__init__.py`) whenever `platform_rt/` changes. Published runners are reused while the version matches.
- **`tp stage run <stage> --run r-N` ignores `--opt`.** Pass changed options as `--input run_options=<file.json>` (the run's options plus yours).
- **Long Docker runs:** `caffeinate -i`, Bash `run_in_background`, never a shell `&`.
- **Each real target found 3–5 platform bugs.** Fix each in the shared code, with a test that fails without the fix, and commit split by owner (`[env]`, `[discover]`, `[generate]`, `[skeleton]`…).
