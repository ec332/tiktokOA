## Differences from the design file

- **The push to the fork went through `gh`'s credentials** (`-c credential.helper=!gh auth git-credential`, `GIT_TERMINAL_PROMPT=0`, a 300 s timeout in `deliver.sh`). Found when pushing the seeded branch: git over HTTPS has no helper here and hung on a prompt. The user's git config is not changed.
- **The evidence term:** "planted bug" is read as a gate row with `seeded` set or `kills > 0`, and "property" as the case technique `property`. Black-box family checks aren't recognised as property evidence yet.
- **Scan's "the report says so":** the whole-spec note is in `run_options.scan`, but the report stage doesn't print it yet.
- **Issue drafts** are written to `data/runs/<run>/issues/<defect>.md` plus `.sh`, and stored in the `delivery` artifact.
