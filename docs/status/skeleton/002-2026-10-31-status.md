## Deviations from the plan

1. S5 "done when" reads "superseding a `cases` artifact marks gate → retest stale". `generate` also consumes `cases`, so it goes stale too. `env` doesn't consume `cases` and stays fresh. The test asserts this, not the literal text.
2. `typescript` is pinned to ^6: TypeScript 7 (native) has no JS API, and `openapi-typescript` needs one.
3. `httpx` stays in place of `httpx2` (Starlette prints a deprecation warning). Swapping the dependency was blocked in this session.
4. Ruff 0.17 formats Python code blocks inside Markdown, and it rewrote a block in the plan. That was reverted, and `*.md` is now excluded from ruff.
5. Added `GET /stages` (the drawer's upload picker needs each stage's `consumes`) and `GET /runs/{id}/events/list` (event history in the drawer).
