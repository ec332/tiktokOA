## 2. How to run

```bash
caffeinate -i uv run tp serve            # API :8000 (restart after ANY backend change; never during a run)
cd web && npm run dev -- --port 5173     # UI http://localhost:5173 (hot reload)
```

## 4. Gotchas learned this session

- The runner image holds the SUT code. It now rebuilds itself in generate when the backend image changes (`generate/stage.py::ensure_runner`).
- The rule suggester leaked facts about the code until its prompt forbade them (`spec/prompts/rule_suggester.md`). Re-check after any prompt change: suggestions must stay general.
- The report's R1 check ("numbers without a composition") walks every number. New free-form fields in the worklist must be added to `report/build.py::POSITIONS` or wrapped in `num()`.
- `docs/*` is git-ignored: add status files with `git add -f`. Commits are owner-tagged and may only touch the owner's paths (`uv run tp check-folders --commits <range>`).
- Run outputs live in `data/` (git-ignored by design): artifacts in `data/artifacts/<sha256>`, generated tests in `data/runs/gate-exec-<id>/tests/`, raw records in `data/runs/execute-<id>/`, report files in `data/runs/report-exec-<id>/`.
